# Jumper rides a segway — and gets on by itself

An entry for the Crab Robot Open-source Challenge 2026. Jumper learns, in MuJoCo
physics, to ride a two-wheeled self-balancing board that it steers only by
leaning; then the board is redesigned, step by step, until the crab can climb on
from the ground by itself. Every motion in the films is a recorded simulation —
there is no hand animation.

日本語の要約：カニロボ Jumper が、体重移動だけで操縦するセグウェイ型ボードの乗り方を強化学習で覚え、さらに「ひとりで乗り込める」ようにボードの形を段階的に改良した記録です。動画の動きはすべて物理シミュレーションの結果です。

## What is in this branch

| Path | What it is |
| --- | --- |
| `tasks/jumper/segway/` | Task `jumper.segway`: ride the board by leaning. The board (`vehicle.py`) and its firmware (`mdp/firmware.py`) are part of the task. `CRAB_BOARD_DESIGN` picks a board, `CRAB_TERRAIN=road` a road with bumps and slopes. |
| `tasks/jumper/segway/face.py` | The crab's face: a mood judged from the IMU and the ride, drawn on the display screen in replays. |
| `tasks/jumper/segway_board/` | Task `jumper.segway_board`: get onto the parked board from the ground and stand on it. |
| `lab/` | Everything around the tasks: prototype, evaluation, recording, Blender town, film edit, Rhino export. |

## Results

**Riding** (`jumper.segway`, 3000 iterations, RTX 3060, about 2 h): the crab tracks
speed and turn commands on the board; 19.8 s of a 20 s episode on average, 4% of
episodes ending in a fall.

**Getting on alone** (`jumper.segway_board`, 128 starts from the ground each,
`lab/eval_board.py`):

| Board | Got on | What stopped it |
| --- | --- | --- |
| Original, 14 cm step | 0% | Too high; the parked board rocks like a seesaw. After a night of training the crab hid under the deck. |
| Low floor 6.5 cm, through axle | 0% | The axle bar crosses the deck at chest height |
| Kneeling deck | 0% | The whole board pitches 19.5° nose-down and never re-engages |
| Low floor 6.5 cm, hub motors (no bar) | 99% | — |
| Hub motors, batteries in hubs, 42 cm deck, step raised 6.5 → 14 cm a little at a time | 98–100% at every height, 99% at 14 cm | — |

Ramp and comb-shaped decks, and stowing ramp flaps, were tried too (`lab/deck_screen.py`,
`vehicle.DESIGNS`): fixed ramps boarded 100% but scrape on a road; a parked board
pitches freely about its axle, so a flap or a kneeling deck rocks it.

**Road** (`lab/eval_ride.py`, 128 × 20 s on flat, bumps and slopes up to ~10°):

| Board and policy | Falls | Episodes that scraped the underside |
| --- | --- | --- |
| Original board, policy trained on flat ground | 10.9% | 35.9% |
| 14 cm hub-motor board, policy trained on the road | 7.0% | 6.2% |

## Reproduce

Set up the framework as its own `docs/PROJECT_GUIDE.md` says (Python 3.10–3.13,
GPU PyTorch, `pip install -e .`), then from the repository root:

```bash
# Ride, then get on, on the 14 cm hub-motor board
CRAB_BOARD_DESIGN=lowcell_h14 CRAB_TERRAIN=road python scripts/train.py --task jumper.segway --num_envs 2048
CRAB_BOARD_DESIGN=lowcell_h14 python scripts/train.py --task jumper.segway_board --num_envs 2048
# (the 99% at 14 cm came from raising the step from 6.5 cm, each height resumed
#  from the one below: see lab/step7.sh)

# Evaluate
CRAB_BOARD_DESIGN=lowcell_h14 python lab/eval_board.py --checkpoint <model.pt> --out eval.json
CRAB_BOARD_DESIGN=lowcell_h14 python lab/eval_ride.py --checkpoint <model.pt> --out ride.json

# Record a replay with the face on the screen
CRAB_BOARD_DESIGN=lowcell_h14 python lab/ride_record.py --task jumper.segway --checkpoint <model.pt> \
    --command-script lab/route_drive.py --video ride.mp4
```

The trained policies are attached to the GitHub release, not committed.
The `lab/*.sh` scripts are the exact runs made during development and expect the
original layout (`lab/` beside the `jumper/` checkout).

| Script | Does |
| --- | --- |
| `segway_proto.py` | The board alone with a box rider: firmware gain scan |
| `eval_board.py`, `eval_ride.py` | Getting-on and road evaluation, as in the tables above |
| `deck_screen.py` | Geometry screen of deck shapes, and ground clearance at the cruise tilt |
| `ride_record.py`, `route_drive.py` | Replays with the face, a route driven by pure pursuit, export for Blender |
| `blender/build_city.py` | The town, built from `city/route.json`, moving recorded poses |
| `progress_video.py`, `make_video.py`, `bgm.py` | The films: learning progress, the entry cut, an optional generated soundtrack |
| `contact_map.py`, `export_rhino.py` | Where the crab touches the deck, exported as Rhino 6 curves |
